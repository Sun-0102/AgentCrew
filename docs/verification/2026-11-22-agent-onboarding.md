迁移前按原方式备份已有数据库。旧群、会话、任务、消息 ID 不变。原厂会话文件不删除。群更换目录时清理实例运行绑定，保留已经同步的可见历史。删除会话时清理其绑定及本地运行副本；外部项目文件不删除。

升级前已 selected、但没有启动意图记录的旧输入，不能证明没有开始执行，因此标为 interrupted_unknown。queued 保留；已经 cancelled 的输入保持终态。启动恢复先核对持久化的原厂完成事件；其他在途尝试进入 interrupted_unknown，等待用户核对，不盲目恢复命令。程序不承诺跨 SQLite 与外部进程恰好执行一次。

## 行为与边界

- 一家同时运行一轮；Codex 和 DeepSeek 可并行。同厂商多个成员按实例排队，共用原厂安装与登录，不代表账号或文件隔离。
- 用户插话按来源优先处理。暂停时当前轮可结束，后续输入留队；继续必须由用户操作。停止先使旧代次失效，再取消运行。
- 进程明确启动失败才按 1、3、10 秒最多重试三次。认证、额度、版本和不明执行结果不自动重发。每群父级会话共用每小时 100 次保护；连续三次相同回复且本轮没有工具依据时暂停。
- 旧默认成员在启动时检查组件。初始化与模型目录读取不发模型任务；原厂认证和额度以真实执行为准。
- 配对只执行应用独立发现的运行组件。请求提供的路径仅做格式约束，不作为命令执行。受支持安装布局及固定 Harness 版本约束继续保留。
- 配对 API 不开放项目读取、任务执行、管理命令或通配 CORS；只监听 127.0.0.1，校验 Host，拒绝 Origin/代理头，限制请求体与时间。此边界不隔离已经控制同一系统账号的程序。
- 邀请有效期十分钟。重启使旧邀请失效。claim 可以用相同 request_id 和相同指纹重试；会替换旧查询令牌。关闭弹窗不撤销邀请。
- 配对服务失败不阻止已有聊天。托盘建立失败时保留正常关闭窗口退出的路径。
- Mac 代码按实际应用包元数据发现 Harness 可执行文件，再检查资源包、固定版本和 SDK 握手；没有真实 Mac 运行证据。当前 Mac 配置没有定制图标或签名，不能作为已完成的 Mac 安装交付。

## 用户验收顺序

以下均未执行。真实发送与交接会使用原厂模型额度；生成邀请、协议检查及组件检查不调用模型。

1. 在本分支自行构建并启动桌面版。核对 schema 15、升级备份和旧群/会话/消息。保留可恢复的原数据备份。
2. 点击左侧“接入”，创建 Codex 邀请，复制给同机 Agent。等待应用显示“已接入，等待任务”。重复相同 claim，确认只创建一个成员。
3. 对 DeepSeek 重复接入。关闭原厂配对聊天，再分别在 AI-gent 私聊发送真实任务，核对消息、模型、工具、审批和取消。
4. 添加第二个同厂商实例，设置不同模型或思考模式。分别私聊，再加入同一群，检查消息归属、上下文和厂商运行槽串行。
5. 在群内提出需要实现与独立复核的任务，观察 A → B → A。空闲后再发消息，检查调度仍可继续。检查引用、代码、附件中的 @ 不触发执行；重名候选使用不同 ID。
6. 运行中插话、暂停、继续、停止。停止后发送新任务，检查旧消息不会再次触发交接。查看并导出任务结果，核对 attempt_id、输入、代次与原厂执行 ID。
7. 隐藏窗口、切换会话、前端重载，再打开。通过托盘暂停全部、继续全部、彻底退出。重启后核对未启动队列、暂停状态、已取消项和不明尝试。
8. 分别核对过期/撤销/错误码、未知厂商、脚本路径、重复 request_id 内容冲突、浏览器 Origin、超大请求、启动两个实例和配对端口失败。对照改进方案 A01–A26 逐项记录，不能以界面状态代替实际调用。
9. Mac 需在 Mac 上单独构建、签名和运行验收：`npm run tauri -- build --config src-tauri/tauri.macos.conf.json`。核对组件安装布局、取消的进程组、托盘、恢复和应用包。Windows 的代码检查不能证明 Mac 可用。

本次仅整理源码与依赖锁文件，没有运行上述步骤，也没有新增或运行测试。已使用 rustfmt 整理新增 Rust 模块；这不构成编译或功能验收。

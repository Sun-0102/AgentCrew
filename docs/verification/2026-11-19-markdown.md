# 聊天 Markdown 验收

消息正文使用 react-markdown 与 remark-gfm，支持 CommonMark 和 GFM 表格、任务列表、删除线。复制仍读取原始消息。原始 HTML 按文字显示，危险链接由解析器过滤。

- `node --test tests/message-body.test.mjs`：表格、常见语法、HTML/链接安全、流式未闭合代码块、消息合并边界。
- `npm run build`：TypeScript 和 Vite 构建通过。修复 ChatStage 原有的回复合并变量类型收窄错误，保持合并规则。
- ego-browser 实际聊天页面：1360、900、680 像素宽度无页面横向溢出。680 像素下表格内部横向滚动，长代码独立滚动。
- 截图：`artifacts/chat-ui/markdown-desktop.png`、`markdown-narrow.png`；尺寸结果：`markdown-results.json`。

浏览器验证使用临时预览消息，完成后恢复原记录。未调用真实 Agent，未重新生成桌面安装包。

# 任务结果与实际文件复核：用户验收步骤

日期：2026-11-19。状态：首批代码已实现，未构建、未测试，待用户验证。

本次只阅读代码、实现、格式化新增 Rust 模块并静态复查改动。未启动应用、运行构建或自动化测试、调用模型或执行界面验收。已有推理强度、速度与 Markdown 改动保留；未新增测试，仅将已有数据库版本断言更新为 11。

## 本次范围

```text
用户任务 → 本轮执行前文件依据 → Agent 执行
                                  ↓
                回复、工具记录、执行后文件依据归档
                                  ↓
         群内 @ 交接 / 用户按需指派另一家复核
                                  ↓
        任务结果 → 用户确认完成 / 结束且不验收 → 导出
```

| 能力 | 本次实现 |
| --- | --- |
| 交接 | 每轮保存任务、序号、执行者、来源 Agent/用户、来源消息、要求和起止时间 |
| 复核依据 | 执行前后保存目录、HEAD、状态、差异和有界文件摘录；上一轮回复和工具记录进入后续上下文 |
| 按需复核 | 等待状态下可在结果页指派另一家读取实际文件，要求列出文件路径、问题位置、依据和未验证项 |
| 任务连续性 | 等待中的未验收任务收到补充后沿用原任务；确认完成或主动结束后才开始新任务；失败、取消、中断后的新指派另建任务 |
| 结果页 | 群右上角“任务结果”；最近 100 项任务；结果、交接与复核、文件依据三个视图 |
| 导出 | 用户选择新文件名，保存 Markdown 或 JSON；不覆盖已有文件；运行中导出如实保留未归档状态 |
| 存储 | schema 11；对旧版本迁移前备份，保留旧项目、消息、推理强度与速度配置 |

## 手动验收

以下步骤由用户自行执行，真实 Agent 任务会消耗对应额度。建议使用专用测试目录。

1. 关闭旧版应用，按平常方式启动更新版。检查已有私聊、群聊、模型与设置仍可查看；应用数据目录应有旧数据库的版本备份。
2. 打开含 Codex、DeepSeek 的群并关联一个小型 Git 项目。任务前保留一处原有修改和一个未跟踪文本文件，便于区分原有状态。
3. 指派 Codex 修改一个小文件，要求完成后交给 DeepSeek 检查具体文件。打开“任务结果 → 交接与复核”，检查执行者、来源消息、交接内容和轮次；两家记录应属于同一任务。
4. 在执行中补充一条要求。确认当前轮结束后优先处理补充；已结束轮次的回复、工具记录和文件依据仍保留，不能被下一轮覆盖。
5. 在任务等待时再发一条修改要求。确认任务 ID 不变，轮次增加，之前的修改和复核仍在同一份记录中。
6. 打开“文件依据”，切换轮次，检查执行前后摘录与实际文件对应；原有修改明确包含在工作区状态中，不能被标为本任务独有产物。
7. 若 Agent 没有主动交接，在任务结果页点击另一家的“复核”。检查群内出现用户指派记录；该 Agent 应通过工具读取实际文件，报告路径、问题位置、依据和未验证项。只有模型说“读过”而无对应依据时，不应将其当作验证通过。
8. 检查结果页将模型回复标作陈述，工具记录单独展开；任务等待时仍显示未验收。点击“确认完成”后显示用户已验收；下一条消息产生新任务。
9. 另起任务并等待回复，点击“结束任务，不验收”。确认状态为已取消，说明明确未验收；旧记录仍可查看，下一条消息产生新任务。
10. 生成中点击停止，检查群任务及已开始轮次结束；后续交接不再派发。原文件不回滚。
11. 在专用任务中关闭并重启应用，检查运行中的任务/轮次显示中断；不自动重发；旧记录仍在，缺失结束快照明确说明。
12. 导出 Markdown 和 JSON 到新的文件名。检查目标、用户补充、来源、各轮回复、工具记录、前后文件依据和限制均在；尝试选择已有文件，应返回错误而不覆盖。
13. 新建任务后回看并导出旧任务。旧任务不能混入新任务的用户消息、模型回复或当前文件状态。更换群关联目录后，旧任务保留原采集目录和快照。

## 边界检查

- 非 Git 目录：聊天与文件任务可继续，结果页说明未获得 Git 文件候选，不能伪报已保存整个项目。
- 新建但尚无初始提交的仓库：HEAD 差异说明缺失，仍可从已跟踪和未跟踪文件候选采集文本。
- 超过 40 个文件、单文件超过 8000 字节或总文本超过 64000 字节：明确显示截断或未采集；提示 Agent 读取实际文件补查。
- 二进制、非 UTF-8、已删除文件、链接和 Windows 重解析点：不读取为普通文本，显示原因。
- 常见敏感文件名（如 `.env*`、私钥和本地数据库）：不采集正文，Git 差异过滤常见敏感路径。此过滤不是内容脱敏保证，工具记录和普通源码仍可能含敏感内容，分享前需检查。
- 仓库子目录作为项目：文件候选相对该工作目录，不应重复拼接仓库前缀或读取目录外文件。
- 旧任务：没有轮次快照时明确说明缺失，不能用当前文件补造历史证据。
- 浏览器预览：不访问本机任务和模型，明确提示使用桌面版。

## 已知限制

实际文件复核目前由明确指派、文件依据及工具记录支持，不做自动判卷。只读是给复核 Agent 的任务要求，未新建系统级只读沙箱。是否实际读取了足够文件、问题是否已修正、测试是否通过，仍需结合实际结果判断。

文件快照只覆盖 Git 可识别的变更候选。干净文件、忽略文件、超限文件和非 Git 项目内容仍由 Agent 通过现有文件工具读取。Git 差异相对采集时 HEAD，不是任务专属差异；多个群共享目录或用户同时改文件时，也不能把全部变化归因于本任务。

执行中仅有执行前快照；回复和工具记录在本轮结束后归档。进程崩溃或退出中断时可能没有结束快照和该轮归档回复，聊天原记录仍保留。导出是工作记录，不包含完整项目文件、登录凭证配置或完整原始协议，不作为项目恢复包。

尚未加入逐项问题的解决状态、完整产物复制与哈希清单、精确耗时/费用统计或并行执行。这些继续排在可靠交接和本轮验收之后。

# 群内需求会话实施记录

状态：已修改代码，未运行验收。用户明确要求不测试、不提交。

## 设计依据

沿用用户确认的自包含 `group-sessions.html`。采用米白背景、陶土色主按钮，保留原 Codex / DeepSeek 图标。群列表页提供群名称、成员、进行中的会话数量与进入入口。进入群后分为群列表、需求会话列表、当前对话三栏。

核心动作是“新建会话”。关键状态包括：新会话空白、进行中 / 已归档筛选、会话搜索无结果、归档只读、重命名弹窗、任务正在执行。复用现有 Dialog 的模态与焦点行为；会话操作菜单支持点击外部和 Escape 关闭。菜单使用短暂淡入与位移动效，减少动态效果偏好下关闭动画。

新会话不继承其他会话历史。旧记录保留为默认会话。私聊、模型选择、技能、附件、审批和任务结果继续使用既有功能，执行命令中的 groupId 指向当前会话的 conversation ID，群设置使用父群 ID。

## 数据与边界

- 迁移 014 增加父群关系和会话元数据；不改写已有消息或任务标识。
- 消息、摘要、关键词检索、任务结果、草稿及会话选择分别绑定当前会话。
- 群成员和工作目录由父群管理。更换关联项目前检查所有子会话的运行和暂停状态；允许更新后同步目录，重置运行时绑定。
- 已归档会话可查看历史与任务结果，不能发送、继续或发起复核；恢复后可继续。
- 新增会话不会抢占运行中的任务。保留现有全局单任务限制，未新增跨会话队列。
- 浏览器预览也支持会话元数据与独立草稿；Agent 执行仍需要桌面版。

## 后续操作入口

成员面板增加直接移出和添加成员。成员变更接口在执行锁内读取最新群信息，按增减成员更新，保留群名、关联项目和历史消息，避免旧界面状态覆盖其他群设置。群内至少保留一位成员，运行和暂停状态沿用群设置限制。

会话行改为独立选择按钮与操作按钮，菜单通过 portal 显示，避免滚动列表裁切。支持点击外部、滚动、改变窗口大小或 Escape 关闭。重命名、归档 / 恢复和删除均可操作未选中的会话。

删除前确认记录范围。后端使用事务校验会话归属及空闲状态，先删除任务子记录，再删除任务、摘要、消息、运行时绑定、偏好和会话元数据。子会话还删除对应的隐藏群行与 conversation 行；默认会话保留父群依赖的基础行。目录更新同时覆盖父群基础行，保证删除默认会话后新建会话仍继承当前项目目录。

删除不触碰项目产物、图片缓存、数据库备份或原厂会话文件。本轮只实现操作，没有通过工具实际移出成员或删除会话，也没有运行测试。

# Codex 独立速度选择

日期：2026-11-19。

后续交互更新：速度下拉框已改为小闪电按钮。点击开启快速，再点切回标准；开启时显示金色背景和实心闪电。继续使用原速度存储和请求参数，与思考强度独立。构建和 7 项前端测试通过；浏览器测试数据验证点击开关分别发送 priority/default，思考强度保持 high，刷新恢复点亮状态。截图：`artifacts/speed/lightning-active-fixture.png`。此次仅调整前端，未重复模型调用或原生桌面点击验收。

- 模型、思考强度、速度分别选择。速度读取 `model/list.serviceTiers`，另加明确的标准速度 `default`；本机账号实际目录返回 `priority`（Fast）。没有广告该档位的模型只显示标准并禁用速度选择。DeepSeek 不显示 Codex 速度控件。
- 前端按 Codex 模型保存速度至独立的 `ai-gent.speed.v1`；原 `ai-gent.reasoning.v1` 保留。切模型按目标模型恢复设置，无效旧速度回退标准。初次使用标准速度，不自动消耗快速额度。
- 私聊传 `serviceTier`，群聊传 `codexServiceTier`。SQLite schema 10 新增独立速度表，按会话及模型保存，供群聊后续调度读取。schema 9 迁移前备份，原思考设置保留。
- 每轮向本机 App Server 的 `turn/start.serviceTierForTurn` 显式传值；切回标准发送 `default`，不继承原线程速度。该字段来自已安装 0.169.0-alpha.11.1 导出的协议定义。模型目录和后端都检查非标准档位是否支持。

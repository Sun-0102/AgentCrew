# 聊天工作台设计

2026-11-19。沿用既有暖色，借鉴用户提供的 Pachat 聊天结构。北极星：像聊天软件一样，直接找到自己的 Agent，围绕任务交流和执行。

## 结构与主动作

```text
Agent 导航 → 私聊 / 群聊列表 → 当前聊天 → 成员 / 执行记录
                               ↓
                      写消息、@、回复、文本附件
```

- 启动桌面版时并行自动连接 Codex 与 DeepSeek，分别显示连接中、就绪或失败；失败保留错误提示和手动重试入口。DeepSeek 的连接不阻塞 Codex 私聊加载。
- 默认进入 Codex 私聊，不要求选择项目。项目目录在“工作空间”登记和切换。
- 左侧保留聊天与通讯录、会话搜索、建群；群聊和私聊上下文分开。
- 创建协作群固定在搜索框下方，位于会话滚动区之外；聊天和通讯录均可使用。移除列表底部及群标题旁的重复建群入口。
- 右上角“群设置”统一管理群名称、本机 Agent 和关联项目；不包含外部邀请、链接分享或多人账号。新群和现有群均可选择项目，现有群保存后保留群 ID 与历史消息。修改关联时说明旧文件保留、Agent 执行会话重建；目录和旧会话索引收进可展开的“工作目录变更记录”。
- Codex 使用真实 App Server；DeepSeek 已接入独立私聊及群内定向执行（新增群聊执行未测试，待用户验证）。@ 菜单或消息开头的 @ 自动切换目标及其模型目录；群消息按实际来源显示头像和名称。DeepSeek 按消息显示回复，并显示本机终端工具暂不可用的限制。
- 消息支持引用、复制、基础代码块和文本附件。附件最多三个，合计 60 KB。
- 成员及执行面板按需打开；窄窗口使用覆盖面板。输入框固定在聊天区底部。

## 视觉与交互

画布 `#faf7f2`，表面 `#fffcf8`，侧栏 `#f5efe7`，导航轨 `#eee5da`，主色 `#a4482e`，正文 `#382e28`。保留奶油白、燕麦和陶土色。系统字体与统一细线 SVG，不增加图片或外部字体依赖。

主角是会话内容和输入框。用户消息靠右，Agent 消息靠左；聊天流只显示实际消息。工具、系统状态日志、派发和目录变更记录统一收进右侧“聊天详情”，默认关闭。数据库保留完整记录，主界面只显示一行当前状态。空群从欢迎区顶部显示。

动效：按钮反馈 140–170ms；聊天/通讯录选中条 220ms；弹窗及遮罩 180–230ms；详情面板 250ms；@ 菜单 160ms。支持减少动态效果。弹窗支持 Escape、背景关闭和返回入口焦点。

## 状态与保存

保留加载、连接、未接入、空记录、无搜索结果、执行中、审批、取消及失败状态。后端校验成员及执行对象。全应用一次运行一个任务；任务期间不能调整当前群成员。

草稿按会话保存，文字可刷新恢复；引用和待发附件在当前运行期间保留。保存失败保留输入并报错。数据库版本 8，升级先备份。群记录使用独立会话和目录，可选关联真实项目。

## 后续任务面板完善目标

采用 Pachat 的群聊分工思路，沿用当前暖色和聊天结构。群聊负责交流，旁侧任务面板负责显示工作进度。窄窗口继续使用覆盖面板，不增加另一套导航。

```text
会话列表 │ 群聊：需求、@、交接、结果 │ 当前任务
         │                         │ 负责人
         │                         │ 执行状态
         │ 输入、发送、取消         │ 交付文件
```

- 面板优先显示当前任务、负责人、执行状态和交付文件；模型、目录、代码差异、验证结果和交接内容按需展开。
- 群内默认协作，直接发需求或 @ 成员，不增加逐条启用开关，不固定角色顺序或修改轮次。
- 执行期间支持暂停后续派发和取消当前执行；用户插话改变方向时，记录决定并显示受影响步骤。
- 区分执行中、等待审批、受阻、未验证、待验收和已完成。触发执行频率保护时显示原因及继续入口。
- 检查结论关联实际文件、差异和命令输出；交付文件可以定位，缺失或不可读时显示原因。
- 保留本机成员邀请；首版不增加公开群、好友或外部邀请。此设计尚未实现或完成截图验收。

## 默认群聊协作增量（已实现，未测试）

移除“允许 Agent 相互 @”复选框与“两轮修改”提示。群聊直接发送任务，成员在普通正文提及对方即可交接。运行中保留可编辑输入框、@ 菜单、附件和发送按钮；停止按钮同时保留。插话先保存并显示待处理数，在当前轮结束后优先处理。未点名的运行中插话默认交给当前负责人，手动点名优先。任务卡显示累计执行次数，不显示固定总轮数，保留暂停、继续、停止与用户确认完成。无新提及时显示等待新消息。

暂停不终止当前执行；暂停后直接发送新消息即可恢复处理。停止取消未执行队列并中断当前运行，聊天和已写文件保留。应用注入的派发内容仍可展开查看，用户留言单独显示。小高度窗口中任务卡内部滚动。以上新增交互均未测试，待用户验证。

## 聊天界面收简增量（已实现，未测试）

主消息流仅显示用户和 Agent 的文字消息，不再插入工具记录、系统调度日志、派发提示或工作目录记录。移除重复“你的 Agent”徽标，展示时去掉消息末尾多余空行。输入框上方只保留一行状态，包含当前执行者和必要的待处理数；不显示大任务卡、重复目标、固定使用说明或 DeepSeek 常驻能力提示。

任务目标、模型、执行次数、暂停/继续/完成控制、错误原因、审批内容、能力限制和所有执行记录放入按需打开的右侧“聊天详情”。状态异常或有审批时提供“查看详情/查看请求”入口，保留审批批准和拒绝。主界面继续保留发送和停止；暂停且当前轮已结束时也能直接停止整个队列。未运行构建、界面测试或真实模型调用，待用户验证。

## 同轮回复合并（已实现，未测试）

同一 Agent 在同一轮执行中产生的多段文字，合并为一个气泡和一组头像、名称、时间。中间工具记录不拆分气泡；用户发言、不同 Agent、新的应用派发、目录变更或状态边界会分开，避免把不同轮次或插话前后的回复混在一起。复制和引用使用合并后的完整文字。只合并显示，不改动 SQLite 原消息及执行记录；未运行构建或测试，待用户验证。

## 窗口缩放布局修正（已实现，未测试）

移除消息行 900px 的固定最大宽度及两类气泡 760/720px 的固定上限。消息行跟随聊天主区宽度，左右发言各靠所在侧；气泡最大宽度按可用区域比例计算。消息区与输入区统一使用 chat-main 的 chat-gutter，窄窗只调整同一间距变量，不再出现宽屏 55px/48px 等不一致留白。头像尺寸和消息间距也参与气泡可用宽度计算。消息行不参与竖向压缩，长回复在消息区内正常滚动；标题栏保留自身高度。未运行构建或窗口缩放测试，待用户验证。

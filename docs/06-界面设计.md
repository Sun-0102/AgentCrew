# 界面方向

2026-11-19：按用户要求，将绿色界面调整为暖色界面。

- 目标：个人桌面 AI 工作台。主动作是选择本地项目目录。
- 配色：奶油白画布、燕麦色侧栏、陶土橙主按钮、深咖文字。区域通过色温与细分隔线区分。
- 排版：保留三栏结构，放大说明与操作文字；项目名称为主标题，成员卡片与证据面板为次级信息。
- 图形：目录、协作和记录使用一致的细线 SVG，不增加图片或外部字体依赖。
- 状态：保留加载、错误、未接入、项目选中和数据库连接状态；禁用控件使用独立颜色。
- 动效：按钮悬停、按下反馈与项目选中颜色过渡；支持减少动态效果。
- 文案：移除英文装饰标题，缩短项目说明，明确记录区域用途。
- 交付：修改现有界面与源图标。不执行测试、截图验收或独立评审，交给用户手动检查。

未验证实际视觉。项目登记、数据库及 Agent 接入逻辑保持现状。
